# 贡献指南

欢迎提交错误报告、兼容性结果、文档和代码改进。贡献遵循 [MIT](LICENSE)。

## 报告问题

请提供 PhoneRescue 版本、Windows/Android 版本、设备型号（不含序列号）、USB 或 LAN、复现步骤、预期和实际表现。涉及 ChatGPT UI 时注明 App 版本和浮窗状态。

不要提交配对码、`session.json`、签名密钥、设备序列号、个人文件、完整聊天 UI dump 或未经清理的日志。可用虚构小文件构造复现。涉及泄露或命令执行边界的问题见 [SECURITY.md](SECURITY.md)。

## 开发与 PR

1. 阅读 [AGENTS.md](AGENTS.md) 和[构建指南](docs/BUILD.md)。
2. 在独立分支修改，保持现有公共接口和幂等语义；如需改变，更新文档和对应客户端。
3. 运行与改动有关的测试。不要为了普通文档修改打断手机任务；不要把编译成功当成 UI 实测成功。
4. PR 写明具体问题、改后行为、实际测试、未验证部分。界面适配最好提供去隐私后的状态描述和真实验证结果。

生成的 APK/ZIP、SDK、构建输出、开发密钥和本机工作区不进入源码 PR。若修改依赖工具版本，更新下载校验值、说明和构建验证记录。
