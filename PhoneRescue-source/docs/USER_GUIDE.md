# 使用指南

## 安装与连接

Windows 包需要完整解压，不要只复制 EXE。Android 安装 APK 后，在开发者选项开启 USB 调试，用数据线连接并允许调试授权。USB 驱动使用手机厂商提供的版本。

启动 `start-usb.cmd`，保持窗口运行。默认监听 `127.0.0.1:18765`，启动后最多等待手机 5 分钟。识别到唯一已授权手机后，建立 ADB reverse，自动打开 APK 并传入配对信息。连接较晚或有多个设备时：

```powershell
.\connect-usb.ps1 -Serial YOUR_ADB_SERIAL
```

手动输入时只需电脑窗口显示的四位数字，包括开头的 0。每次重启电脑端都会换码。监控程序会恢复丢失的 USB 转发，但不会自动重新执行中断的电脑命令。监控程序不在运行时可再次执行 `connect-usb.cmd`。

## 四个页面

| 页面 | 作用 |
| --- | --- |
| 任务 | 填写目标、选模板、开启/停止自动循环、查看日志 |
| 文件 | 上传手机文件、刷新工作区、保存产物到手机 |
| 连接 | 四位码/局域网地址、无障碍权限入口 |
| 高级 | 手动命令、JSON 导入、工作目录、结果与旧请求恢复 |

## ChatGPT 自动任务

在“连接”页进入无障碍设置，手动开启“电脑急救桥 · 自动维修”。如果系统提示受限设置，请使用设备提供的正常授权流程。打开官方 ChatGPT App，新建空白对话，返回急救桥填写任务并启动。

首次建议保持只读模式，目标填“只调用一次 system 检查，然后总结”。运行时保持手机解锁，ChatGPT 在前台；浮窗可停止或查看日志。默认 8 轮，可选 1–20 轮；会话上限 15 分钟，单次等待回复最长 3 分钟。

关闭只读模式后，模型可提出 PowerShell 命令，浮窗会显示目的、完整命令、目录和超时；确认后才执行。修改后的检查和模型总结可能需要额外轮次。更多细节见 [AUTOMATION.md](../AUTOMATION.md)。

## 文件加工

1. 在“文件”页选文件，允许系统文件选择器读取你选择的内容。
2. 上传成功后进入“任务”页，写清输入、目标格式与成功条件。例如：“把 inbox 中的 CSV 转为 JSON，保留中文和字段名，将结果写入 outbox，读取 JSON 验证后总结。”
3. 原件在工作区 `inbox/<随机目录>/原文件名`；重名文件不会覆盖。输出应写入 `outbox`。
4. 任务完成后手动刷新文件列表，选“保存到手机”，在系统保存界面指定位置。

单文件最多 100 MB，列表最多显示 200 个文件，模型每轮文件清单还有文本长度限制。大项目可先打包为 ZIP，让模型在工作区解压。文件不会自动删除；用电脑文件管理器按需整理。

传输失败后重新选择文件上传或保存。上传中断不会展示 `.uploading` 临时文件；下载中断可能留下不完整的手机文件，请删除或重新保存。字节通过 USB/局域网传输；命令输出如果包含文件内容，会随自动循环发送到 ChatGPT。

## 手动模式

在“高级”页粘贴 PowerShell 或 JSON，点击“从剪贴板导入”或通过其他 App 分享文本。检查后点击执行。示例：

```json
{"command":"Get-Date | Out-String","workingDirectory":"C:\\Users\\Public","timeoutSeconds":60}
```

工作目录必须在电脑存在；优先使用连接后自动填入的工作区。结果可复制回任意聊天模型。电脑服务允许当前用户权限范围内的命令，不会自动提权。

## 局域网与 iPhone

退出 USB 电脑服务，再运行 `start-lan.cmd`。手机与电脑连接同一可信局域网，将电脑配对地址中的 `127.0.0.1` 替换为电脑局域网 IPv4。LAN 使用长凭证。

Android 可填完整地址；iPhone 在 Safari 打开完整地址，使用网页的文件和命令功能。必要时只在 Windows 专用网络放行端口 18765，不需要路由器公网转发。LAN 为明文 HTTP。iPhone 暂不支持本项目的 USB 和 Android 无障碍自动循环。

## 中断与恢复

- 提交后断线：先重新连接查询原请求，不要再次提交相同工作。请求编号只在当前服务器进程内有效。
- 服务重启：先查看 `%LOCALAPPDATA%\PhoneRescue\logs` 和实际文件状态，再决定是否清除旧请求追踪。
- 停止或超时：尝试终止进程树，不会回滚文件和设置。
- APK 更新/进程终止：自动循环不会自动续跑；部分手机会关闭无障碍服务，需要手动重新开启。

## 常见问题

| 现象 | 排查 |
| --- | --- |
| `failed to connect` | 电脑服务是否运行；数据线是否支持传输；`adb devices` 是否为 `device`；运行 `connect-usb.cmd` 恢复转发 |
| `unauthorized` | 解锁手机并允许 USB 调试；不要把离线模拟器当作手机 |
| 找不到 ADB 设备 | 检查手机厂商驱动、USB 模式、数据线；不要直接套用其他机型注册表修改 |
| HTTP 401 | 电脑服务换码了，重新运行连接脚本或输入当前四位码 |
| 无障碍服务未开启 | 回连接页手动开启；更新、系统省电或测试工具可能中断服务 |
| 找不到输入框 | 确认 ChatGPT 已登录、空白对话在前台；回报 App 版本、设备型号、状态文字，不上传含聊天内容的完整 UI dump |
| 填好了但没发送 | 按浮窗提示手动点一次发送；不要重复点击 |
| 编译器/转换工具不存在 | 安装所需工具，或让模型使用已安装的替代工具；电脑断网时无法自动获得缺失依赖 |
| APK 签名不一致无法覆盖 | 开发者构建密钥与已安装版本不同；先备份必要配置，再选择同一签名版本或自行卸载重装 |

结束使用时先停止任务，再关闭电脑程序；可拔下 USB。不要公开 `session.json`、完整执行日志、签名私钥或个人上传文件。
