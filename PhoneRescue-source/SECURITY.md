# 安全边界与问题报告

PhoneRescue 是本人电脑上的命令执行工具，不是多用户服务或命令沙箱。默认 USB 只监听 loopback，四位码为本地便捷配对；它不能防御同机恶意进程或所有共享本机网络的客户端。LAN 使用长凭证，但 HTTP 没有传输加密。

Android 自定义命令审批属于客户端行为，直接 HTTP/CLI 没有相同确认框。API 凭证持有者可执行当前 Windows 用户权限内的 PowerShell。不要公网暴露，不自动提权，不把私人账户凭证送给模型。输出过滤只能识别部分常见敏感字段。

如果发现路径逃逸、凭证泄露、请求去重失效或意外执行问题，请优先使用 GitHub 仓库 Security 页中的私人漏洞报告（维护者启用后）。若该入口未启用，请联系维护者请求私人渠道，不要在公开 Issue 放入可用凭证或个人数据。

项目处于实验阶段，没有承诺维护或响应 SLA。发布签名私钥由维护者私下保管；源码和 CI 不包含私钥。下载发布包后可对照 Release 中的 SHA256SUMS.txt 校验。
