# ChatGPT 官方 App 自动任务（0.3）

本版不需要 API Key、不反代私有接口、不提取 ChatGPT 登录凭证。通过 Android 无障碍服务操作官方 ChatGPT 的聊天界面，由手机移动网络访问模型；电脑只接受 USB / 局域网命令。

## 首次设置

1. 安装 `release/PhoneRescue-0.3.apk`（覆盖升级，保留配对配置），电脑端同步更新到 0.3 便携版。
2. 保持 `start-usb.cmd` 运行；它会自动建立 USB 转发、传入配对码。稍后才连接手机可以运行 `connect-usb.cmd`。
3. 查看“已连接”状态；手工配对只需在“连接”页填四位码。局域网仍填完整地址和长凭证。
4. 在急救桥“连接”页点“开启无障碍服务”，在 Android 设置中手动开启“电脑急救桥 · 自动维修”。更新 APK 后部分手机需要重新开启。
5. 打开 ChatGPT，新建空白对话并清空输入框。返回急救桥填写问题描述。

## 开始自动循环

- 首次建议保持“只读诊断模式”勾选，目标填写：`只调用一次 system 诊断，然后总结，不执行 shell。`
- 点“开始自动循环”，确认发送目标和诊断结果到当前 ChatGPT 对话。
- 程序会打开 ChatGPT，自动填写和发送请求，读取带本轮标识的操作，执行固定诊断，再自动回传结果。
- 保持手机解锁、ChatGPT 在前台。界面悬浮条显示阶段，并提供“停止”和“查看日志”。
- 默认最多 8 轮，可设为 1–20 轮；会话最长 15 分钟；等待每次聊天回复最长 3 分钟。
- 如果 ChatGPT 发送按钮无法识别，程序会保留已填入的文本并提示手动点一次发送，之后继续读取回复。

## 维修模式

取消勾选“只读诊断模式”后重新开始会话。预设诊断仍然自动执行；**模型提供的每条自定义 PowerShell 命令必须由你在浮动确认框逐次批准**。确认框显示目的、影响、恢复说明、完整命令、目录和超时。

拒绝某一步会将拒绝结果回传模型。修复执行后要求继续诊断验证。模型总结不等于独立保证问题已修复，请对照实际结果。

## 自动执行的范围

程序可自动执行固定的 system、network、proxy、agent_tools、services、disk、build_tools 检查，以及 files 工作区清单。模型不能通过给 diagnose 添加 command 字段替换实际命令。任意自定义命令均按 shell 处理并请求确认，只读模式下直接拒绝。

## 编译、运行与文件转换

先在“文件”页上传原文件，再在“任务”页选模板并填具体要求。模板会关闭只读模式，允许模型提出需要逐次确认的 shell 操作。每条命令最多 300 秒，仍受总会话 15 分钟限制。

模型每轮获得工作区路径，可用 files 获取上传文件完整路径。原件在 inbox，代码、加工结果、报告应放 outbox；不要覆盖原件。内置提示要求检查本机已有工具，依据失败输出修正，验证运行结果或转换内容，完成前列出产物。是否支持特定语言、视频或 Office 格式取决于电脑已有编译器和转换软件。

文件不通过 ChatGPT 附件上传：文件字节在手机与电脑之间走 USB/局域网，模型接收文件路径、命令输出和清单。若命令读取文件内容并输出，该内容会作为结果发入聊天。回传产物时在“文件”页点刷新，选择“保存到手机”并指定保存位置；单文件 100 MB 上限。中断传输需重新选择上传或保存。

每轮使用新的随机回复标识。完整标记和合法 JSON 出现、生成停止、内容稳定后，才处理操作。连续重复同一操作会停止。中途切换到其他 App 时不读取其界面，不在其他 App 中填写或发送内容。

## 中断与恢复

- 停止会尝试取消当前电脑命令，不能撤销已经发生的修改。
- 电脑请求提交或查询发生网络错误时不自动重新执行，保留原请求编号。回急救桥重新连接查询结果；仅在核实电脑状态后清除旧请求追踪。
- 手机进程被终止、重启或无障碍服务关闭后，不会自动续跑维修会话。已执行日志仍可查看。
- 不读取密码和登录凭证。会读取当前 ChatGPT 可访问的界面节点，但只解析本轮标识对应的回复，不保存整个聊天页面。
- 自定义命令输出可能含敏感信息；程序会隐藏配对密码及部分常见密钥字段，不能保证识别所有形式的敏感数据。

## 当前验证范围

0.2 修复后已在荣耀 Magic V3 通过 ChatGPT 连续自动执行网络及工具环境诊断。0.3 电脑 API 测试覆盖四位码、文件字节往返、重名文件、路径限制、真实 C# 编译运行及中文 CSV 转 JSON。新版 APK 编译及签名验证通过；手机端验证进展见 `VALIDATION.md`。

官方 App UI 更新、登录状态、网络、回复格式、折叠屏或多显示器布局均可能影响界面适配。自动任务不等于对生成代码和产物的独立质量保证，应检查执行输出与下载结果。

DeepSeek 暂未作为本版的主要适配目标。iPhone 不支持这套 Android 无障碍自动化；仍可使用原来的手动局域网网页入口。
